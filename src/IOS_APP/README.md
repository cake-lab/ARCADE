# ARCADE iOS App

iOS app for viewing the ARCADE live stream on your iPhone or iPad.

## Prerequisites

- Xcode (latest version recommended)
- iOS device or simulator
- ARCADE server running (see main [README](../../README.md))

## Build and Run

1. Open `ARObjectPlacement.xcodeproj` in Xcode.
2. Select your target device.
3. Build and run the app.

## Usage

1. **Enter server details**: On first launch, enter the server **IP address** and **port** (default: 5034).
2. **Connect**: Tap **save** to establish a connection to the ARCADE server.
3. **select start recording**: Once connected, you will see the live stream from the server.

Make sure the ARCADE server is running and reachable on your network before connecting.
